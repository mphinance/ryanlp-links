# Ryan LePiane Link Hub

A link-in-bio page you own. One static `index.html`, no build step, no monthly fee.

**To change your links:** edit `config.js` and save. The page updates in about a minute. That is the only file you need to touch.

**Latest posts:** the tape and "The Weekly Book" refresh from your Substack RSS once a day through `.github/workflows/posts.yml`. If a refresh fails, the page keeps showing the last good posts.

**Colors:** the `:root` block at the top of `index.html`.
